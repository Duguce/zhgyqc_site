# Bundled theme subset

Source: https://github.com/hongtaoh/hugo-ht

This directory is a checked-in subset, not a Git submodule or an unmodified
upstream checkout. Site-owned templates and styles have moved to the repository's
root `layouts/` and `assets/`. Remaining shortcodes and media support existing
content. Unused example content, demonstration logos and obsolete scripts were
removed. Keep `LICENSE.md` and the original upstream attribution in `README.md`.

Use the repository root README and Makefile for development and deployment.
